# Погода Мики — Томск

Это самостоятельный проект Мики. Здесь мы строим собственный погодный анализатор для Томска.

## Архитектура

- ECMWF IFS
- DWD ICON
- NOAA GFS
- GEM
- RainViewer
- локальные наблюдения Томска
- онлайн-камеры как источник фактической обстановки
- далее: аэропорт, Яндекс Погода, спутниковые данные, погодавттомске и обучение весов по исторической точности

Модельный прогноз не выбирается вслепую: источники сравниваются, рассчитывается согласованность и формируется сводный результат.

## Веб-приложение

Статическая PWA-версия находится в корне репозитория.

На главной странице показываются текущее состояние, сводный анализ, модели, камера-наблюдение, часы и дата. Карта радара работает через MapLibre/OpenFreeMap и RainViewer.

## Камеры

Видеопотоки не выводятся на страницу. Сборщик периодически получает кадр из онлайн-потока и сохраняет только численные/текстовые признаки, которые используются движком анализа.
