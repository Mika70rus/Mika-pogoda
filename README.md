# Погода Мики (Томск)

## Получить APK без Android Studio (GitHub Actions)
1. Создайте пустой репозиторий на github.com и загрузите в него всё содержимое этой папки
   (включая скрытую папку .github).
2. Вкладка Actions -> Build APK -> Run workflow (или просто сделайте push в main).
3. Когда сборка позеленеет, откройте её и скачайте артефакт PogodaMiki-debug-apk.
4. Распакуйте, перенесите app-debug.apk на телефон и установите
   (разрешите установку из неизвестных источников).

## Или через Android Studio
Откройте папку как проект, дождитесь синхронизации Gradle, нажмите Run.

Это отладочная сборка (подпись debug), для личного использования.
